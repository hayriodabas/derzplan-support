Field support

For help or a bug report, open a support issue. A free GitHub account is required. Issues are public: do not post private project names, customer information, notes or backups. Support documentation is currently available in English and Turkish.

Set up the two walls

Create a project, choose units, then enter the width and height of walls A and B. Both bases use the same elevation reference. Enter actual measured tile dimensions; the product name is only a label.

Separate grout from perimeter gaps

Internal grout is the joint between neighboring tiles. Enter the four surrounding gaps separately for each wall. The right edge of A and the left edge of B meet at the corner. Each wall keeps its own perimeter allowance.

Choose the starting line

Drag the common reference in the drawing, use the slider, or type the first horizontal joint center. Independent horizontal starts and continuation across the corner are explicit choices. No automatic reuse of an offcut is assumed.

An uncovered edge or narrow cut

A start that leaves only grout at a usable edge is an invalid drawing. Adjust the start or revert. Narrow-piece alerts compare with your own minimum threshold; they are not an installation standard or a safety judgment.

PDF and saved alternatives

Standard PDF export is free. It records the selected source and layout revision, all piece IDs, units, and a site-check note. Saved alternatives can retain earlier measurements; inspect the earlier-measurements banner before export. Compare a temporary shift for free; Pro enables additional saved alternatives.

Back up and import

Open Projects → Settings → Export complete backup, then choose a destination in Files. A completed save is confirmed afterward. Backups contain project measurements and notes and are not encrypted by DerzPlan. Use a trusted location. Import validates a backup and adds separate copies. Existing projects remain. Extra imported projects are archived if the free active-project slot is occupied.

Deleted work and damaged files

The last 50 deleted projects remain in Recently deleted. Restoring returns a project to the archive. If a notebook cannot be decoded, its original is preserved. Export the original recovery file and import a known-good backup; do not treat the damaged original as a validated backup.

Purchase or restore Pro

Settings → Explore Pro → Restore purchases, using the Apple Account that purchased Pro. Apple handles payment, pending approval and refunds. Store operations need a network connection. Existing work, standard PDF and backups remain accessible if Pro access ends. Pro is a one-time non-consumable purchase, not a subscription.
